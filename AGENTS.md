# Rules for Agents

Plan: `guardfork.md`. Kill thresholds: `config/kill.toml`. Measurements and decisions: `NOTES.md`.

1. **Implementation ownership:** Agents may implement `guardfork/guards/rules.py` (G1–G5; frozen as `guards-v1`, edits require a version bump), `guardfork/fork/select.py`, `guardfork/fork/probe_plan.py`, `guardfork/train/losses.py`, and `guardfork/stats/` **except `guardfork/stats/bayes_prior.py`, which Arnav hand-writes** (change-point oracle, Laplace guard prior, sequential Beta stopping); for it agents write only `NotImplementedError` stubs, docstrings and failing `@pytest.mark.handwritten` specs (`tests/handwritten/`). Other spec tests (`tests/test_*_spec.py`) are the contract for agent-implemented code; keep them passing. Pre-registration lives in `PREREGISTRATION.md`; the design/evaluation scenario split in `config/dev_set.toml` is binding.
2. **Loader-level split lock:** `test_normal` loads only with `allow_final=True` (`--final`). Never work around it.
3. **No API teachers or API-generated training data.** All student rollouts, continuations and Q2 training data use open-weight models only. Evaluation-only, zero-rollout judge baselines in Q1 may query hosted open-weight endpoints (`judge_open`, primary) and one proprietary frontier judge (`judge_claude`, non-training API) strictly as diagnostic rows in the Q1 table. Judge outputs never enter any training pool or checkpoint selection; any continuation launched only because of a `judge_claude` pick is tagged `eval_only` and excluded from pair export. API keys come from environment variables only (`--api-key-env`); the pre-commit hook blocks key patterns.
4. **No Google code, data, or results. No plaintext AppWorld task data in git.** The pre-commit hook (`git config core.hooksPath hooks`) blocks `runs/`, `results/`, `forks/`, `teacher/`, `jobs/`, `appworld_initial_context.json`, `*.tar`, `*.jsonl`, and AppWorld task text. Hold any public push or post until outside-work approval clears.
5. **Reproducibility:** every trial logs `commit_sha`, `config_hash`, `harness_hash` (incl. compose hash and `PYTHONHASHSEED=0`), `model_id`, `backend`, `train_seed`, `eval_seed`, `env_seconds`, `container_limits`.
6. **Never modify AppWorld or Harbor verifiers / task checkers.**
7. **Measure before building:** do not launch Weekend 1+ Harbor/GPU jobs until Weekend 0 numbers in `NOTES.md` pass `config/kill.toml`. Show a plan before adding dependencies. Offline unit tests of W1+ code are allowed.
